# moon-mirror
This project ranks five Earth sites by how closely they match the Moon's south pole on five measurable traits. Every input value has a source.

Result (equal weights): Dry Valleys 0.64, Haughton Crater 0.59, Iceland (Askja) 0.39, Atacama 0.29, Death Valley 0.28. The winner stays the same when any one trait counts double too

Files
moonmirrorprog.py: the scoring code. Run it in Google Colab or any Python 3 environment with pandas and matplotlib.
ranking.csv, similarity_per_trait.csv, ranking.png : outputs written by the script.
